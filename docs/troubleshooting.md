# Troubleshooting record

The completed-work inventory includes troubleshooting across:

- Wazuh agents and configuration.
- Linux kernel and systemd behavior.
- Virtual machine networking.
- SSH and service connectivity.
- DNS configuration and connectivity.
- Detection behavior and duplicate alerts.

The record does not include incident-level symptoms, exact commands, root causes, or corrective changes. Those details are deliberately not reconstructed.

## Case study format for future evidence

For each real troubleshooting case, capture the observed symptom, affected scope, evidence collected, hypotheses tested, confirmed cause (or remaining uncertainty), actual change, and verification. Include rollback or side effects only when they were part of the work. Keep unresolved findings explicit.

This is a documentation format, not a claim that additional cases have been completed.
